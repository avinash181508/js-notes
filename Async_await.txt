Promises & Async/Await in JavaScript

In JavaScript, dealing with asynchronous code (like fetching data from a server, reading files, or timers) can be tricky because it runs in the background without blocking the rest of your code. The classic way to handle asynchronous code in JavaScript used to be callbacks, but this can lead to what's known as "callback hell" (when callbacks are nested too deep). To improve this, Promises and async/await were introduced to handle async code in a more manageable way.

1. What is a Promise?

A Promise is an object that represents the eventual completion (or failure) of an asynchronous operation and its resulting value. You can think of a promise as a placeholder for something that hasn’t completed yet, but will at some point in the future.

A Promise can be in one of three states:

Pending: The promise is still in progress.

Resolved (Fulfilled): The promise completed successfully.

Rejected: The promise failed.

Creating a Promise

You create a promise using the new Promise() constructor. It takes a callback function with two parameters: resolve and reject.

resolve(value): Used when the promise completes successfully.

reject(error): Used when something goes wrong and the promise fails.

Example of a Promise:

let myPromise = new Promise((resolve, reject) => {
    let success = true;

    if (success) {
        resolve("The operation was successful!");
    } else {
        reject("Something went wrong.");
    }
});

myPromise
    .then(result => {
        console.log(result); // "The operation was successful!"
    })
    .catch(error => {
        console.log(error); // "Something went wrong."
    });


Here:

.then() is used to handle the successful result (when the promise is resolved).

.catch() is used to handle any error (when the promise is rejected).

2. Chaining Promises

You can chain multiple .then() calls. Each .then() will wait for the previous one to finish before executing.

Example of Promise Chaining:

let myPromise = new Promise((resolve, reject) => {
    resolve(10);
});

myPromise
    .then(result => {
        console.log(result); // 10
        return result * 2;  // 20
    })
    .then(result => {
        console.log(result); // 20
        return result + 5;  // 25
    })
    .then(result => {
        console.log(result); // 25
    });

3. Using async and await

async and await are syntactic sugar introduced in ES2017 (ES8) to make working with Promises easier and more readable. They allow you to write asynchronous code in a way that looks like synchronous code, without needing to manually chain .then() and .catch().

async Functions

An async function always returns a Promise. If the function returns a value, it’s wrapped in a resolved promise. If the function throws an error, it’s wrapped in a rejected promise.

Example of async function:

async function myAsyncFunction() {
    return "Hello from async!";
}

myAsyncFunction().then(result => {
    console.log(result); // "Hello from async!"
});

await Keyword

The await keyword can only be used inside an async function. It pauses the execution of the async function until the Promise resolves and returns the result. This makes asynchronous code easier to read.

Example of await:

async function fetchData() {
    let promise = new Promise((resolve, reject) => {
        setTimeout(() => resolve("Data fetched!"), 2000); // Simulating async operation
    });

    let result = await promise; // Wait for the promise to resolve
    console.log(result); // "Data fetched!" (after 2 seconds)
}

fetchData();


In this example:

The await pauses the function until the promise resolves. This looks like synchronous code, but it's actually asynchronous.

4. Handling Errors with try / catch in async/await

When using async/await, errors are handled using the traditional try/catch block, which makes it easier to read and manage errors.

Example of error handling with async/await:

async function fetchData() {
    try {
        let response = await fetch('https://jsonplaceholder.typicode.com/posts');
        if (!response.ok) {
            throw new Error("Failed to fetch data");
        }
        let data = await response.json();
        console.log(data);
    } catch (error) {
        console.log(error); // "Failed to fetch data"
    }
}

fetchData();

5. Practical Example of async/await with Multiple Promises

You can handle multiple asynchronous operations using async/await in combination with Promise.all() or await in loops.

Example of multiple async tasks with Promise.all():

async function fetchData() {
    let task1 = fetch('https://jsonplaceholder.typicode.com/posts');
    let task2 = fetch('https://jsonplaceholder.typicode.com/users');

    let [posts, users] = await Promise.all([task1, task2]); // Wait for both requests to complete
    posts = await posts.json();
    users = await users.json();

    console.log(posts, users); // Posts and Users data
}

fetchData();


In this example, Promise.all() waits for both promises (task1 and task2) to resolve before proceeding, which is more efficient than waiting for each one sequentially.

Summary

Promises allow you to handle asynchronous operations with .then() and .catch().

Async/await allows you to write asynchronous code that looks synchronous and is easier to read, using async functions and the await keyword.

Always use try/catch for error handling in async/await to manage any issues with your asynchronous operations.

Key Points:

Promises give you a cleaner way to deal with asynchronous operations.

Async/await makes asynchronous code even more readable and avoids "callback hell".
